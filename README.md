# 📊 Super Store Sales Dashboard

This project is an interactive Power BI dashboard designed to analyze Super Store sales data across different regions, customer segments, and time periods. The dashboard enables users to explore key metrics like revenue, profit, quantity sold, and discount effects.

---

## 📌 Objective

The main goal of this project is to:
- Perform sales performance analysis using visual tools
- Identify patterns and trends across different customer segments, shipping modes, and regions
- Provide business insights for strategic decision-making

---

## 🗃 Dataset

- The dataset used in this project is a public sample retail dataset commonly known as the **Superstore dataset**.
- It includes columns like `Order Date`, `Sales`, `Profit`, `Quantity`, `Category`, `Segment`, `State`, `Region`, and `Shipping Mode`.

---

## 💡 Key Features

- **KPI Cards**: Show key metrics (Revenue, Profit, Quantity) by year
- **Time-based Analysis**: Sales trends by year, quarter, and month
- **Segment & Category Visuals**: Sales share by customer segment and product category
- **Shipping Mode Breakdown**: Performance of Standard Class, First Class, etc.
- **Geographic Insights**: Sales by state and region (map visuals)
- **Interactive Filters**: Allow user to filter by region, category, state, and more
- **Bubble Chart**: Plots Discount vs Sales vs Profit to show discount impact
